# Mobile App

**Tech Stack:** Flutter (Dart)

## Responsibility

This is the customer-facing mobile application for the Pay As You Maintain platform. It provides:

- **Onboarding & Authentication** — guided sign-up, KYC, and consent flows.
- **Dashboard** — real-time view of policy status, premium breakdown, driving score, and maintenance score.
- **Telematics Visualisation** — trip history, driving behaviour insights, and usage trends.
- **Maintenance Tracker** — logging service records, uploading receipts, and viewing upcoming maintenance reminders.
- **Claims Filing** — submitting claims with photo/document uploads and tracking claim status.
- **Notifications** — receiving push alerts for advisories, premium changes, and policy updates.
- **Policy Management** — viewing policy details, downloading documents, and managing renewals.

## Getting Started

```bash
flutter pub get
flutter run
```
